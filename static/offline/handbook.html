Открытый справочник

🩸

Кровотечение

  1. Спокойно удерживайте питомца, наденьте защиту на руки.
  2. Наложите стерильную/чистую повязку с сильным давлением на рану 5–10 минут.
  3. При кровотечении с конечности — приподнимите её выше уровня сердца, если нет травмы позвоночника.
  4. Не давайте обезболивающие без врача. Везите в клинику.
🫁

Остановка / затруднение дыхания

  1. Проверьте, нет ли инородного тела во рту (осторожно, без форсирования).
  2. Откройте окно, снизьте стресс, не разогревайте питомца.
  3. Если дыхания нет — немедленно в клинику; по дороге позвоните врачу.
  4. Не делайте искусственное дыхание без инструкции врача — риск травмы.

[схема] Стабильное положение, контроль дыхательных движений.

☠️

Отравление

  1. Сохраните упаковку, остаток вещества, оцените количество и время.
  2. Не вызывайте рвоту без указания ветеринара (часть ядов опаснее при рвоте).
  3. Не давайте молоко «для нейтрализации» без консультации.
  4. Срочно в клинику с образцом.
🌡️

Тепловой удар

  1. Уберите на солнце/из жары, обеспечьте прохладу и обдув (вентилятор).
  2. Смочите лапы, ушные раковины прохладной (не ледяной) водой.
  3. Дайте пить понемногу, если питомец в сознании.
  4. При ступоре, рвоте, судорогах — немедленно в клинику.

[схема] Прохлада + влажные лапы + транспорт.

⚡

Судороги

  1. Уберите мебель с острыми углами, не держите язык силой.
  2. Засеките длительность приступа.
  3. После окончания — тишина, затемнение, в клинику.
  4. Повторные приступы подряд — срочно.
